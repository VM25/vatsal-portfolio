# Clearing (Portfolio V2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the portfolio homepage as "Clearing": one continuous page over a scroll-driven Hudson night-to-morning scene, with an interactive pricing exhibit, a market-making sequence, an evidence-led research chapter, and full mobile, reduced-motion and no-WebGL support.

**Architecture:** Next.js App Router page made of five server-rendered chapters with static content from `src/data`. A single client `World` component renders one raw-WebGL fragment shader (or pre-rendered stills) behind the page, driven by scroll progress. All numerics (pricing, the market-making toy, scene state) live in pure, unit-tested modules in `src/lib`; client exhibits only render them.

**Tech Stack:** Next.js 16.2.7, React 19.2.4, TypeScript 5, Tailwind CSS v4 (tokens in `globals.css`), raw WebGL 1, Canvas 2D, Vitest (unit), Playwright (browser, Chromium/WebKit/Firefox).

**Spec:** `docs/superpowers/specs/2026-11-06-clearing-design.md`. Visual reference: `docs/superpowers/specs/clearing-reference/prototype-source.html` (shader source, chapter shots, exhibit behaviour and final copy — port from it, don't redesign).

## Global Constraints

- All work on branch `v2-clearing`. Never commit to or merge into `main`. Never run `netlify deploy --prod`, change DNS, or touch the production site. Previews only (`netlify deploy --alias v2-clearing`), and only after Task 13.
- Read `node_modules/next/dist/docs/` before writing App Router code (this Next.js has breaking changes; see `AGENTS.md`).
- No three.js. One raw-WebGL full-screen shader; everything else DOM, SVG or Canvas 2D. Remove `gsap`, `framer-motion`, `scrollama` if unused at the end.
- Fonts only: Geist 200–500, Geist Mono 400–500, STIX Two Text 400–500 + italic (via `next/font/google`).
- Palette tokens exactly: `--night #0B1214`, `--night-2 #111A1D`, `--night-3 #1A2528`, `--night-deep #060A0B`, `--fog #C3CBC6`, `--fog-hi #E6EBE7`, `--fog-mid #9AA39E`, `--fog-lo #5B6661`, `--sodium #FFA62B`, `--sodium-glow #FFC873`, `--sodium-deep #C77A10`, `--ink #13201F`, `--ink-mid #3E4B48`.
- Copy: no em dashes (U+2014) or `--` in site copy; no framework/process words in copy; sentence case; findings stated as discoveries.
- Facts: graduating December 2026; full-time quantitative roles from January 2027; FRM text "GARP FRM Part 1 Candidate · November 2026" appears only in Path; route Mumbai → Arizona → New Jersey.
- Secondary text ≥ 14px; touch targets ≥ 44×44px; no horizontal scroll at 320px.
- No contact form; no phone number. Profile photo `public/images/vatsal-maniar.jpg`, unfiltered, in Path only.
- Numbers display with true minus "−" (U+2212) and en-US thousands separators.

## Review Focus

1. **WebGL context lost mid-session** (GPU reset, tab backgrounded on iOS): the scene must swap to the stills, never go blank. Test added to Task 6.
2. **Rotating a phone or resizing mid-scroll:** the scene switches between landscape and portrait composition, chapter key positions and section clock labels are re-measured, the clock stays consistent with scroll. Test added to Task 6.
3. **Mashing "Run it again" during the market-making run:** only one run is active, every update reconciles, and the final state equals a single clean run. Test added to Task 11.
4. **Deep link to `/#research`:** the page loads scrolled there with the scene, clock and active nav matching Research, and the premise and claims fully visible. Test added to Task 12.
5. **Keyboard-only use of the pricing sliders:** arrow keys change N, the readouts update (N=13 → 10.0665) and are announced through the live region. Test added to Task 10.
